FRONTLINE AG SOLUTIONS — JULY 2026 DASHBOARD PROTOTYPE

Open index.html in a browser. The dashboard is a standalone file and requires no server or external JavaScript libraries.

WHAT IS ACTUAL
- July 1–31, 2026 top-line channel KPIs from the Frontline AG Lumina export:
  Display, YouTube, STV, Premium Plus STV, Social, SEM, Email and AMPED.
- Frontline Ag's 10 current Montana dealership locations from the company website.

WHAT IS MODELED FOR THE PROTOTYPE
- Dealership-level impression allocation and saturation targets.
- Named creative concepts and asset-level allocation/performance.

WHY THE MODELED LAYER EXISTS
The supplied Lumina presentation provides high-level channel/product totals but not the granular dealership impression or creative asset tables required for the requested views. The prototype demonstrates exactly how those data would behave once a raw geo and creative export is connected.

KEY INTERACTIONS
- Toggle channel, dealership, map metric and creative metric.
- Click dealership bubbles or rows to isolate a location.
- Use quick buttons for Bozeman/Belgrade and Great Falls.
- Creative view toggles among delivery share, performance rate and attributed actions.
- Feedback notes are saved locally in the viewer's browser.

NOTE ON BOZEMAN
Frontline's official store listing is Belgrade. The prototype labels it “Bozeman / Belgrade” to match the requested Bozeman market framing.
